Meta Quest 3 · APK 3504 · неподвижная гарнитура · 90 секунд после прогрева каждого режима. Реальные новые кадры игры (AlyxMetrics), без повторных отправок и кадров timewarp. Главная серия — фиксированные 100%; TAAU — отдельное сравнение при 67%. Эталон для каждого разрешения — среднее двух запусков без сглаживания.

Timewarp 36 кадров/с / 72 Гц; MQSR выключен, текстуры 512 / mip 0 / пул 512 МиБ. VRS сохранён на «Максимальный»: Off, TAA, TAAU и SMAA допускают 4×4; MSAA ×2 и гибрид — до 4×2, MSAA ×4 — до 2×2. Значения отражают режим целиком с его ограничениями VRS. При 67% Off близок к лимиту 36 FPS: измеренная разница кадровой частоты не равна полной стоимости обработки на GPU. Это оценка одной сцены и конфигурации, а не универсальная стоимость алгоритма.
